# OW-FABLE-A — fairness findings, locks 01–05

Method: each lock cold-read as a fresh player from board text + epigraph +
journal notes alone (no hints, no source). Finding → fix → where it now lives.
Deterministic checks for every fix: `artifacts/wip-fable-a/feel-gate.mjs`.

## Findings → fixes

1. **02 — the premise was hidden.** Nothing on the board or journal said a
   pouch is clipped and runs light; the player learned WHAT they were looking
   for only from hint 1. Fixed: stated in the law line, the journal, and the
   epigraph ("— and one runs light"). The *level-beam ⇒ clipped stood aside*
   inference is deliberately NOT pre-stated: it is a one-step deduction from
   stated facts (sworn-equal + one light + sinks-heavier), and hint 2 still
   rescues it honestly. A deduction is not a hidden rule.

2. **03 — the goal was only implied.** "Once they burned as one" is lore, not
   an instruction; the target (next night all three burn together) surfaced
   only through wrong-answer near-lines. Fixed: law line and journal now say
   "Set it to the next night on which all three burn as one."

3. **01 — near-lines judge by ætt, but nothing showed the ættir.** "The first
   ætt stands true" was unusable without knowing where an ætt begins. Fixed:
   the rail now carries worn pigment bands (blood/fjord/pine) and carved
   divider notches at 6|7 and 11|12; aria and a journal note name the split
   (six, five, five).

4. **05 — undefined terms.** Status/aria speak of the "standing" and
   "running" band; nowhere were they defined. Fixed: journal note — standing
   runs north–south, running west–east.

5. **All — keyboard semantics were on-board only.** The help paragraph is
   visible but ephemeral; the journal (the player's durable record) never
   held the key map. Fixed: each board writes a one-time "By key: …" journal
   note on first focus of its primary control.

## Near-miss "show WHERE" calibration (per lock, at the near-line's own grain)

- **01** rail underlines per ætt — gold stands / ember does not. Exactly the
  near-line's granularity; cleared on the next touch.
- **02** the weighing that already clears the named pouch gets an ember frame
  (same fact the near-line states); cleared on the next naming/strike/reckon.
- **03** braziers standing dark on the refused night get ember rings; their
  ledger rows read "stands dark" in bold bone (bone, not ember, for the 4.5:1
  body-text floor). The near-line already gives the count.
- **04** three cases: wrongly-struck oath → that testimony marked (it "keeps
  the rivet law"); parity fault → ember edges on the offending lapped pair(s)
  — rivet counts are public, so this is bookkeeping the player could do;
  lap-lawful but misordered → gold ticks up from the keel, ember on the first
  wrong strake, mirroring "N strakes stand true; the next does not."
- **05** deliberately only the FIRST doubling-over along the band is marked
  (two cells), never the full fault map. A full map would let iterate-submit
  replace tracing entirely; count (near-line) + one place (board) sends the
  player back to the band. Documented dead branch: on a closed band the
  break count is always even, so the "one place" near-line text cannot fire;
  kept because verify must stay total over arbitrary answers.
